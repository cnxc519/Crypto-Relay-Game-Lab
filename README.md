# BTC Replay Lab

一个给自己训练盘感用的本地历史回放工具。直接打开 `index.html` 即可使用，不需要安装前端依赖。

## 现在支持的功能

- 训练大厅：盲测快局、趋势猎人、假突破、暴跌生存、错题复仇
- 每局结算评分、XP、等级、每日任务、成就
- 七个角色可选择和培养，角色有经验、阶级、材料和专属试炼
- 导入 BTC 历史 OHLCV CSV
- 切换 `1m / 5m / 15m / 1h / 4h / 1d / 1w`
- 从小周期自动聚合到大周期
- 隐藏未来 K线，逐根揭晓
- 随机训练和随机盲测
- 播放、暂停、上一根、下一根、快进
- 鼠标拖拽平移、滚轮缩放、双击回到当前 K线
- 单击图表任意已显示 K线，直接把当前时间线移动过去
- 拖动黄色当前时间虚线，缓慢微调当前 K线
- 对数坐标、MA20、MA60
- 模拟现货买卖
- 止损价、止盈价，回放推进时自动触发
- 按单笔风险百分比自动计算买入仓位
- 胜率、最大回撤、交易数、R 倍数统计
- 交易理由、错误标签、K线标注、水平线
- 训练会话保存和载入
- 导出交易 CSV、导出复盘 Markdown、保存图表截图

## 直接使用

推荐运行本地服务，这样页面会优先快速导入 `data/BTCUSDT-15m.bin`，如果缓存不存在会自动回退到 `data/BTCUSDT-15m.csv`：

```powershell
python .\start_app.py
```

也可以直接双击 `启动BTC回放.bat`，或者双击 `BTC Replay Lab.lnk` 快捷方式。

它会打开 `http://127.0.0.1:8765/index.html`。如果你只是双击打开 `index.html`，浏览器会限制网页自动读取本地 CSV，这时仍然需要点击右上角 `导入 CSV` 手动选择。

CSV 支持两类格式：

```csv
timestamp,open,high,low,close,volume
1502942400000,4261.48,4313.62,4261.32,4308.83,47.181009
```

或者 Binance 原始 kline CSV：

```csv
1502942400000,4261.48,4313.62,4261.32,4308.83,47.181009,1502943299999,...
```

想从小周期聚合到大周期，建议导入 `15m` 或更小周期的数据。例如导入 `15m` 后可以切到 `1h / 4h / 1d / 1w`。

## 下载 BTCUSDT 历史数据

脚本不需要第三方依赖，使用 Binance 的公开历史归档和可选 API 尾部数据。脚本会自动把 Binance 归档中可能出现的微秒时间戳统一转换成毫秒时间戳。

```powershell
python .\scripts\download_binance_klines.py --interval 15m --out .\data\BTCUSDT-15m.csv
```

也可以下载 1h 或 4h：

```powershell
python .\scripts\download_binance_klines.py --interval 4h --out .\data\BTCUSDT-4h.csv
```

下载完成后，在页面里导入生成的 CSV 即可。

如果希望默认自动导入更快，可以把 CSV 预处理成二进制缓存：

```powershell
python .\scripts\build_candle_cache.py .\data\BTCUSDT-15m.csv .\data\BTCUSDT-15m.bin
```

## 常用快捷键

- `Space` 播放或暂停
- `← / →` 上一根或下一根
- `Shift + ← / →` 一次移动 10 根
- `Ctrl + ← / →` 一次移动 50 根
- `PageUp / PageDown` 一次移动 25 根
- `Home / End` 跳到最早或最新
- `B` 全买
- `S` 全卖
- `M` 添加当前 K线标注
- `H` 添加当前价格水平线

## 游戏模式怎么玩

1. 打开后等 `BTCUSDT-15m.csv` 自动导入完成。
2. 在右侧 `训练大厅` 点一个模式，例如 `盲测快局`。
3. 先选 `看多 / 看空 / 观望`。
4. 用右方向键、播放按钮或拖动黄色线推进 K线。
5. 到终点会自动结算，也可以点 `结算本局`。
6. 结算页会给方向、交易结果、风控、耐心、复盘评分，并发 XP 和成就。

## 角色养成

右侧训练大厅里可以选择七个角色。当前角色会在每局结算时获得经验和专属材料；如果你的行为符合角色风格，会有额外材料。点击 `开启角色试炼` 会进入这个角色最适合的训练模式。

游戏模式使用本局独立资金。开局会创建一份临时账户，结算后恢复外部模拟账户；长期只继承 XP、成就、角色经验和材料。

普通 `角色试炼` 主要获得角色经验。`进阶试炼` 才会掉真正的进阶材料，并且本局无杠杆收益至少达到 `5%` 才能获得材料。

不同角色有不同交易规则，例如风控角色必须先设止损，复盘角色必须先写理由，观望角色限制频繁买入。自动止损止盈不会被这些角色规则拦截。

角色系统设计稿在 [BTC-replay-character-system.md](./BTC-replay-character-system.md)。

## 当前时间线操作

- 单击图表：当前时间线跳到点击位置
- 拖动黄色虚线：默认约每 8 像素移动 1 根 K线，适合慢慢校准
- `Alt` 拖动黄色虚线：更细，约每 18 像素移动 1 根 K线
- `Shift` 拖动黄色虚线：更快，约每 3 像素移动 1 根 K线
- 按住图表空白处拖动：平移当前视图

## 会话说明

训练会话会保存交易、标注、水平线、笔记、账户状态和当前位置。为了避免浏览器本地存储塞入几十 MB 的行情数据，会话不会保存原始 K线，所以载入会话前需要先导入对应 CSV。
