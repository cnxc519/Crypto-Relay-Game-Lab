# Monday Morning Reversal Strategy (周一早盘反转策略)

## 策略逻辑

- **时间窗口**: 每周一 UTC+8 0:00-6:00
- **触发条件**: 早盘波动 0.5%-2%（默认最优阈值 0.6%）
- **方向**: 反向开仓（跌→买入，涨→做空）
- **入场**: 6:00 收盘价
- **平仓**: 同日 24:00 收盘价
- **手续费**: 假设为 0

## 关键发现

1. **2024 是唯一的全面亏损年份** — 所有阈值在 2024 年均亏损，可能与 BTC 减半前后的极端行情有关
2. **2023 表现最好** — 趋势性强、波动适中，胜率高达 67-73%
3. **极端波动有害** — 早盘波动 >2% 时策略大幅亏损（2021-01-11 -17%, 2020-03-16 虽赚但属极端行情），上限卡 2% 一致有效
4. **阈值太低噪音大** — 0.1-0.2% 虽然累计收益高，但交易频率过高，实战难以执行
5. **阈值太高样本不足** — 0.7-0.8% 每年仅 10-20 笔，统计意义弱

## 结论

周一早盘反转策略最优参数为 **早盘波动 0.6%-1.6%**，109 笔交易 +36.74% 累计，胜率 59%。上限是核心——超过 1.6% 的极端波动几乎全部延续而非反转。年均 ~17 笔，频率适中、高胜率，适合作为独立辅助信号。
